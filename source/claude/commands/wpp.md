Show the "what do you want to do now?" menu right now, on demand.

Read `~/.claude/base_project/references/command-menu.md` and render it verbatim — same
file, same content as the menu that shows up automatically at session start (see
`CLAUDE.md`'s "WhatsApp-style" menu instruction). This command is how the user brings it
back later: the menu is never shown on its own after a task.
